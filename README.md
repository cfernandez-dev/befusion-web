# Estampados Fusion Cali 🎨

**Creatividad 100% Caleña** - Sitio web oficial de Estampados Fusion Cali, especialistas en estampados personalizados desde 2012.

## 🚀 Características

- ✅ **100% Estático** - Sin dependencias de servidor
- ✅ **Responsive** - Optimizado para móviles y desktop
- ✅ **Carga Dinámica** - Sistema modular con secciones independientes
- ✅ **SEO Optimizado** - Meta tags completos y sitemap
- ✅ **Carga Rápida** - CDN global de Vercel
- ✅ **HTTPS Automático** - Certificado SSL incluido

## 🛠️ Tecnologías Utilizadas

- **HTML5** - Estructura semántica
- **CSS3** - Estilos modernos con variables CSS
- **JavaScript ES6+** - Funcionalidades interactivas
- **Vercel** - Hosting y CDN
- **Font Awesome** - Iconos
- **Google Fonts** - Tipografía Poppins

## 📱 Compatibilidad

## 🔧 Personalización

### Cambiar Contenido
Edita los archivos en `sections/` para modificar:
- Información de la empresa
- Servicios ofrecidos
- Galería de trabajos
- Información de contacto

### Cambiar Estilos
Modifica `styles.css` para personalizar:
- Colores (variables CSS en `:root`)
- Tipografías
- Espaciados
- Animaciones

### Agregar Funcionalidades
Extiende `script.js` para añadir:
- Nuevas secciones
- Formularios de contacto
- Integraciones con APIs
- Analytics
